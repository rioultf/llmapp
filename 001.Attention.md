## Mécanisme de l’attention

Historiquement, l’alignement de séquences d’items requiert l’insertion d’un encodeur/décodeur de *contexte*.

```mermaid
flowchart LR
    subgraph Inputs["Entrées"]
        direction LR
        x1(("$$x_1$$"))
        x2(("$$x_2$$"))
        x3(("$$x_3$$"))
        x4(("$$x_4$$"))
    end

    subgraph Outputs["Sorties"]
        direction LR
        y1(("$$y_1$$"))
        y2(("$$y_2$$"))
        y3(("$$y_3$$"))
    end

    Enc["Encoder"]
    c["Contexte"]
    Dec["Decoder"]

    x1 --> Enc
    x2 --> Enc
    x3 --> Enc
    x4 --> Enc

    Enc --> c --> Dec

    Dec --> y1
    Dec --> y2
    Dec --> y3
```

### Seq2Seq

On considère une *séquence d’entrée* :

$$
(x_1, x_2, x_3, \dots, x_T)
$$

```mermaid
flowchart LR
    x1(("$$x_1$$")) --> x2(("$$x_2$$"))
    x2 --> x3(("$$x_3$$"))
    x3 --> dots["$$\dots$$"]
    dots --> xT(("$$x_T$$"))
    style dots fill:transparent,stroke:none,color:#000000
```

On définit également une *séquence de sortie* (*a priori* de longueur différente) :

$$
(y_1, y_2, y_3, \dots, y_{T'})
$$

```mermaid
flowchart LR
    y1(("$$y_1$$")) --> y2(("$$y_2$$"))
    y2 --> dotsOut["$$\dots$$"]
    dotsOut --> yT(("$$y_{T'}$$"))
    style dotsOut fill:transparent,stroke:none,color:#000000
```

#### 1. Encodeur : construction du contexte global

L’encodeur traite la séquence d’entrée pas à pas :

$$
h_t = f_{\mathrm{enc}}(x_t, h_{t-1}), \quad t = 1, \dots, T
$$

```mermaid
flowchart LR
    xt(("$$x_t$$"))
    subgraph EtatsInternes["États internes"]
        direction LR
        hprev(("$$h_{t-1}$$"))
        ht(("$$h_t$$"))
    end

    xt --> f["$$f_{\mathrm{enc}}$$"]
    hprev --> f
    f --> ht
```

Le *contexte global unique* est alors défini comme :

$$
c = h_T
$$

Toute l’information de la séquence d’entrée est *compressée* dans ce vecteur.

---

#### 2. Décodeur : génération conditionnée par le contexte

Le décodeur est initialisé par le contexte :

$$
s_0 = c
$$

Puis, à chaque pas de temps, il génère un état interne :

$$
s_t = f_{\mathrm{dec}}(y_{t-1}, s_{t-1}), \quad t = 1, \dots, T'
$$

```mermaid
flowchart LR
    subgraph EtatsExternes["États externes"]
        direction LR
        sprev["$$s_{t-1}$$"]
        st["$$s_t$$"]
    end
    sprev --> fdec
    yprev["$$y_{t-1}$$"] --> fdec["$$f_{\mathrm{dec}}$$"]
    fdec --> st
```

La probabilité du token de sortie est donnée par :

$$
P\!\left(y_t \mid y_{<t}, x_1, \dots, x_T\right) = \mathrm{softmax}(W_o s_t)
$$

```mermaid
flowchart LR
    st["$$s_t$$"] --> Wo["$$W_o$$"]
    Wo --> soft["softmax"]
    soft --> pt["$$P(y_t)$$"]
```

---

#### 3. Résumé fonctionnel

Le résumé fonctionnel du mécanisme est :

$$
\boxed{
\begin{aligned}
c &= \mathrm{Encoder}(x_1, \dots, x_T) \\
y_t &= \mathrm{Decoder}(y_{<t}, c)
\end{aligned}
}
$$

```mermaid
flowchart LR
    x["$$x_1,\dots,x_T$$"] --> Enc["Encoder"]
    Enc --> c["$$c$$"]
    c --> Dec["Decoder"]
    Dec --> y["$$y_t$$"]
```

### Transition vers l’attention

Dans un modèle avec attention, le contexte devient *dépendant de t* :

```mermaid
flowchart LR
    subgraph InputsAttn["Entrées"]
        direction LR
        xa1(("$$x_1$$"))
        xa2(("$$x_2$$"))
        xaDots["$$\dots$$"]
        xaT(("$$x_T$$"))
    end

    EncAttn["Encoder"]

    subgraph StatesAttn["États internes"]
        direction LR
        h1(("$$h_1$$"))
        h2(("$$h_2$$"))
        hDots["$$\dots$$"]
        hT(("$$h_T$$"))
    end

    subgraph AttentionBlock["Attention"]
        direction TB
        alpha1["$$\alpha_{t1}$$"]
        alpha2["$$\alpha_{t2}$$"]
        alphaDots["$$\dots$$"]
        alphaT["$$\alpha_{tT}$$"]
        ctx(("$$c_t$$"))
    end

    DecAttn["Decoder"]

    subgraph OutputsAttn["Sorties"]
        direction LR
        ya1(("$$y_1$$"))
        yaDots1["$$\dots$$"]
        yt(("$$y_t$$"))
        yaDots2["$$\dots$$"]
        yaT(("$$y_{T'}$$"))
    end

    xa1 --> EncAttn
    xa2 --> EncAttn
    xaDots --> EncAttn
    xaT --> EncAttn

    EncAttn --> h1
    EncAttn --> h2
    EncAttn --> hDots
    EncAttn --> hT

    h1 --> alpha1
    h2 --> alpha2
    hDots --> alphaDots
    hT --> alphaT

    alpha1 --> ctx
    alpha2 --> ctx
    alphaDots --> ctx
    alphaT --> ctx

    ctx --> DecAttn

    DecAttn --> yt

    style xaDots fill:transparent,stroke:none,color:#000000
    style hDots fill:transparent,stroke:none,color:#000000
    style alphaDots fill:transparent,stroke:none,color:#000000
    style yaDots1 fill:transparent,stroke:none,color:#000000
    style yaDots2 fill:transparent,stroke:none,color:#000000
```

Cette dépendance temporelle se formalise par :

$$
c \longrightarrow c_t = \sum_j \alpha_{tj} h_j
$$

```mermaid
flowchart LR
    h1["$$h_1$$"] -->|$$\alpha_{t1}$$| sum["$$\sum$$"]
    h2["$$h_2$$"] -->|$$\alpha_{t2}$$| sum
    h3["$$h_3$$"] -->|$$\alpha_{t3}$$| sum
    sum2["$$\dots$$"] -->|$$\alpha_{tT}$$| sum
    sum --> ct["$$c_t$$"]
```

Chaque sortie reconstruit ainsi son propre contexte.

Le schéma récapitulatif suivant oppose le mécanisme sans attention et sa version attentive :

```mermaid
flowchart LR
    subgraph Classical["Sans attention"]
        direction LR
        xClass(("$$x_1,\dots,x_T$$")) --> EncClass["Encoder"]
        EncClass --> cClass(("$$c$$"))
        cClass --> DecClass["Decoder"]
        DecClass --> yClass(("$$y_1,\dots,y_{T'}$$"))
        noteClass["Contexte unique"]
        cClass -.-> noteClass
    end

    subgraph WithAttentionRecap["Avec attention"]
        direction LR
        xAttn(("$$x_1,\dots,x_T$$")) --> EncAttnRecap["Encoder"]
        EncAttnRecap --> hSeq(("$$h_1,\dots,h_T$$"))
        hSeq --> AttnRecap["Attention"]
        AttnRecap --> cAttn(("$$c_t$$"))
        cAttn --> DecAttnRecap["Decoder"]
        DecAttnRecap --> yAttn(("$$y_1,\dots,y_{T'}$$"))
        noteAttn["Contextes spécifiques à t"]
        cAttn -.-> noteAttn
    end

    cClass -. "$$\neq$$" .-> cAttn
    AttnRecap -. "$$\alpha_{t1},\dots,\alpha_{tT}$$" .-> cAttn
```

## Pondération locale du contexte

Le mécanisme d’attention remplace un *résumé global unique* par un *mécanisme de pondération locale*.

Formellement, pour chaque entrée $x_i$, la sortie associée est :

$$
y_i = \sum_j w_{ij} x_j
$$

```mermaid
flowchart LR
    xj["$$x_j$$"] -->|$$w_{ij}$$| sum["$$\sum$$"]
    sum --> yi["$$y_i$$"]
```

---

## Décomposition : query, key, value

Pour produire $y_i$, l’entrée $x_i$ est projetée en requête :

$$
q_i = W_q x_i
$$

```mermaid
flowchart LR
    xi["$$x_i$$"] --> Wq["$$W_q$$"]
    Wq --> qi["$$q_i$$"]
```

Chaque entrée $x_j$ est projetée en clé :

$$
k_j = W_k x_j
$$

```mermaid
flowchart LR
    xj["$$x_j$$"] --> Wk["$$W_k$$"]
    Wk --> kj["$$k_j$$"]
```

La similarité est donnée par :

$$
w'_{ij} = q_i^\top k_j
$$

```mermaid
flowchart LR
    qi["$$q_i$$"] --> dot["$$q_i^\top k_j$$"]
    kj["$$k_j$$"] --> dot
    dot --> wijp["$$w'_{ij}$$"]
```

La normalisation softmax définit les poids :

$$
w_{ij} = \frac{\exp(w'_{ij})}{\sum_m \exp(w'_{im})}
$$

```mermaid
flowchart LR
    wijp["$$w'_{ij}$$"] --> soft["softmax"]
    soft --> wij["$$w_{ij}$$"]
```

Les valeurs sont projetées par :

$$
v_j = W_v x_j
$$

```mermaid
flowchart LR
    xj["$$x_j$$"] --> Wv["$$W_v$$"]
    Wv --> vj["$$v_j$$"]
```

La sortie finale est :

$$
y_i = \sum_j w_{ij} v_j
$$

```mermaid
flowchart LR
    vj["$$v_j$$"] -->|$$w_{ij}$$| sum2["$$\sum$$"]
    sum2 --> yi["$$y_i$$"]
```

---

## À retenir

L’attention permet à chaque token de *définir un critère de similarité*, d’évaluer toutes les autres positions selon ce critère, puis de *combiner les informations pertinentes* pour construire une représentation contextuelle adaptée à la décision.
