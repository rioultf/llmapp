# Présentation 2h — Découverte de la programmation objet, du web et des mathématiques

Cette session suppose que les participant·e·s maîtrisent la gestion des fichiers (textes ou données), savent travailler avec un terminal Linux sans recourir à la souris, conservent l’historique de leurs itérations via git et adoptent une démarche d’essais/tests itératifs pour fiabiliser leur code.

## 1. Objectifs de la session
- Comprendre en quoi la programmation objet aide à structurer la pensée algorithmique.
- Relier le développement web à des concepts mathématiques (séquences, fonctions, flux).
- Montrer comment orchestrer un cas concret (vidéo/démonstration) pour consolider les apprentissages.

## 2. Déroulé (90 min + 30 min Q&A)

### Partie 1 — Fondations (30 mn)
1. **Intro rapide** : Pourquoi la programmation objet ? (5 mn)
2. **Concepts mathématiques associés** :
   - Séquences et indices, rôle des fonctions (10 mn)
   - Exemples concrets (diagrammes Mermaid si besoin)
3. **Transition vers le web** (5 mn)
4. **Résumé fonctionnel** : lien entre notion math, objets et interface (5 mn)

### Partie 2 — Programmation objet appliquée (25 mn)
1. Présentation d’un petit modèle de classe/objet (diagramme UML minimal).
2. Démonstration vidéo : construction d’un module objet simple.
3. Explications mathématiques derrière (règles de mise à jour d’état, flux d’appel).
4. Résumé fonctionnel + transition vers le web.

### Partie 3 — Introduction au web (25 mn)
1. Architecture d’une page web : requête → serveur → réponse.
2. Illustration avec HTML/CSS/JS (transparents + courts extraits de code).
3. Démonstration vidéo/orchestration : interaction entre objet back-end et UI.
4. Résumé fonctionnel global (encapsulé dans un cadre LaTeX).

### 30 min de questions

## 3. Vidéos/démonstrations envisagées
- Orchestration objet ↔ API web (extrait en vidéo ou en live).
- Diagramme de flux Mermaid pour chaque équation clé si demandé.

## 4. Éléments à préparer
- Transparants par grande section (intro, objet, web, démo).
- Diagrammes mathématiques + Mermaid associés.
- Références au contenu du cours existant pour la suite.
